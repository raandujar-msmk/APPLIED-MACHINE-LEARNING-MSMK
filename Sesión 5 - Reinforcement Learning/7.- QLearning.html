Q-Learning - Laberinto interactivo

Demostración del algoritmo Q-Learning para la toma de decisiones.

1. Agente vs. Red Neuronal

En este demo, la Tabla Q almacena el conocimiento. En Deep Q-Learning (DQL), la Tabla Q es reemplazada por una Red Neuronal Profunda que actúa como un aproximador de función Q(s, a).

La red recibe el Estado (s) como entrada y produce los Q-Values de todas las Acciones (a) como salida.

2. El Ciclo RL (Trial-and-Error)

RL opera en un ciclo continuo: El Agente observa el Estado (s), elige una Acción (a), el Entorno le da una Recompensa (r) y un nuevo Estado (s').

A diferencia del aprendizaje supervisado, aquí no hay "etiquetas correctas", solo una señal de Recompensa para optimizar la política a largo plazo.

3. La Ecuación de Bellman

El aprendizaje se basa en la Ecuación de Bellman (o Diferencia Temporal - TD):

Q(s, a) ← Q(s, a) + α ⋅ TD Error

El agente aprende al comparar el valor que esperaba recibir (Q(s, a)) con el valor actualizado que percibe después del paso (que incluye la recompensa inmediata r y el valor futuro descontado γ max Q').
