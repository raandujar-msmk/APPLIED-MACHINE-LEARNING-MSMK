Paradigmas Fundamentales del Aprendizaje Automático

Visualización de los enfoques para resolver el problema de Clasificación de Frutas 🍎🍌🍊

🏷️

Aprendizaje Supervisado (SL)

Enfoque: Clasificación (Predicción)

Aprende de datos etiquetados (entrada → salida correcta). Como un estudiante con un profesor que corrige cada tarea.

El Robot Clasificador

  • 1. Datos de Entrenamiento:

    El modelo recibe imágenes de frutas con sus etiquetas correctas: {(Rojo, Redonda) → Manzana}, {(Amarillo, Curva) → Banana}.

  • 2. Proceso de Aprendizaje:

    La Red Neuronal (o clasificador) ajusta sus pesos para minimizar el error entre su predicción y la etiqueta real.

  • 3. Objetivo Final:

    Clasificar correctamente una fruta nueva y nunca vista con la etiqueta Manzana, Banana u Naranja.

🔍

Aprendizaje No Supervisado (UL)

Enfoque: Agrupamiento (Estructura)

Encuentra patrones y estructura oculta en datos sin etiquetas. Como un niño que agrupa objetos por similitud sin conocer sus nombres.

El Robot Clasificador

  • 1. Datos de Entrenamiento:

    El modelo recibe solo las características de la fruta: {(Rojo, Redonda)}, {(Amarillo, Curva)}. **No hay etiquetas.**

  • 2. Proceso de Aprendizaje:

    El algoritmo (e.g., K-Means) mide la similitud y agrupa las frutas en Clústeres (Grupos). Grupo 1 = Manzanas, Grupo 2 = Bananas, etc.

  • 3. Objetivo Final:

    Dividir el conjunto de datos en K grupos naturales, revelando la estructura interna sin saber qué es realmente una "Manzana".

🚀

Aprendizaje por Refuerzo (RL)

Enfoque: Decisión Secuencial (Ensayo y Error)

Un agente interactúa con un entorno y aprende una política a través de recompensas y castigos, sin un conjunto de datos estático.

El Robot Clasificador

  • 1. Datos de Entrenamiento:

    No hay datos. El agente está en un Entorno (la línea de clasificación) que le da recompensas.

  • 2. Proceso de Aprendizaje:

    El robot toma una acción (lanza una fruta a la Bandeja A), recibe una Recompensa (+1) si acierta o un Castigo (-1) si se equivoca.

  • 3. Objetivo Final:

    Aprender una Política (una función de decisión) que le diga qué acción tomar en cada estado para maximizar la recompensa total acumulada.

Resumen Clave: La diferencia en el "Entrenamiento"

Supervisado: Aprende a imitar el comportamiento correcto a partir de ejemplos etiquetados por humanos.

No Supervisado: Aprende a descubrir la organización subyacente de los datos por sí mismo.

Refuerzo: Aprende a actuar para lograr un objetivo mediante la interacción continua con el entorno (prueba y error).
