Contexto: ¿Cuándo y Por Qué Usarlo?

Cuándo usar RAG: Úsalo cuando necesites que el LLM base sus respuestas en información específica, privada o muy reciente.

  • Para "chatear" con tus propios documentos (PDFs, bases de datos).
  • Para responder preguntas sobre eventos ocurridos después de su fecha de corte de entrenamiento.
  • Para reducir alucinaciones, forzando al LLM a usar fuentes verificables.

Cuándo usar CoT: Úsalo para tareas que requieren razonamiento complejo y de varios pasos.

  • Problemas de matemáticas o lógica.
  • Preguntas de razonamiento de sentido común.
  • Cuando el LLM se equivoca en la respuesta final pero el proceso es casi correcto.
  • Simplemente añadiendo "Piensa paso a paso" al prompt se activa esta técnica.

Cuándo usar el Ajuste de Contexto: ¡Casi siempre! Es la base del control de LLMs. Se usa para definir la personalidad, el rol, el formato de salida y las reglas del LLM.

  • Para que el LLM actúe como un "experto en marketing" o un "pirata".
  • Para forzar que la respuesta sea siempre un JSON, una tabla o código.
  • Para establecer reglas (ej. "Nunca te disculpes", "Sé siempre conciso").
