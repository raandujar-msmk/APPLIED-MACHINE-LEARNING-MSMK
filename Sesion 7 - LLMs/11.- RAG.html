¿Qué es RAG?

RAG (Retrieval-Augmented Generation) es una técnica que "aumenta" la capacidad de un Modelo de Lenguaje Grande (LLM) conectándolo a una base de conocimientos externa (tus documentos).

Esto permite que el LLM responda preguntas usando información específica y actualizada que no estaba en sus datos de entrenamiento, reduciendo "alucinaciones" y citando sus fuentes.

1. Zoom-in: ¿Cómo funciona la "Recuperación"?

Este es el proceso de "búsqueda inteligente". En lugar de buscar palabras clave, busca por significado.

Fase A: Indexación (Antes de preguntar)

  1. 1. División (Chunking): Tus documentos se dividen en "trozos" (chunks) más pequeños (ej. párrafos).
  2. 2. Creación de Embeddings: Cada "chunk" se convierte en un vector numérico (un "embedding") usando un modelo de IA. Este vector representa su significado.
  3. 3. Base de Datos Vectorial: Estos vectores se almacenan en una base de datos especial que permite buscar por "cercanía" conceptual.
Diagrama: Indexación

Documento → Chunks → Modelo de Embeddings → Vectores en la Base de Datos

Fase B: Búsqueda (Cuando preguntas)

  1. 1. Embedding de la Pregunta: Tu pregunta también se convierte en un vector usando el mismo modelo de embeddings.
  2. 2. Búsqueda Vectorial: El sistema busca en la base de datos los "chunks" cuyos vectores estén matemáticamente más cerca del vector de tu pregunta (usando "similitud de coseno").
  3. 3. Obtención del Contexto: El texto de los chunks más relevantes (ej. el Top-3) se extrae. Este es el "contexto" que se usará en el siguiente paso.
Diagrama: Búsqueda

Pregunta → Vector → Búsqueda en DB Vectorial → Chunks Relevantes (Contexto)

(En esta demo, simulamos la búsqueda vectorial con una búsqueda de palabras clave simple para que el proceso sea más fácil de visualizar).

2. Zoom-in: ¿Cómo funciona la "Aumentación"?

Este paso consiste en construir el prompt perfecto para el LLM. Es el núcleo de RAG.

En lugar de enviar solo la pregunta al LLM, usamos una "Plantilla de Prompt" (Prompt Template) para combinar tu pregunta con el contexto que acabamos de recuperar.

Plantilla de Prompt (Ejemplo)

Eres un asistente servicial. Responde la pregunta del usuario basándote únicamente en el siguiente contexto.
Si la respuesta no está en el contexto, di "No lo sé".

Contexto:
---
[... Aquí se inserta el Contexto Recuperado (Paso 1) ...]
---

Pregunta:
[... Aquí se inserta la Pregunta Original del Usuario ...]

Respuesta:

Este prompt "aumentado" fuerza al LLM a basar su respuesta en los datos que le proporcionaste, previniendo que invente información (alucinar) y asegurando que use tu base de conocimientos.

Diagrama: Aumentación

(Contexto + Pregunta) → Plantilla de Prompt → Prompt Aumentado Final
