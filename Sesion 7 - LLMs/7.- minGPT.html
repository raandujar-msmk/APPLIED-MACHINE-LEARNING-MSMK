Introducción a minGPT

`minGPT` es una implementación mínima y limpia de GPT (Generative Pre-trained Transformer) escrita en PyTorch. Su autor, Andrej Karpathy, la diseñó con fines educativos.

Objetivos Principales

  • Simple y Educativo: El código es corto, limpio y fácil de leer. No hay abstracciones innecesarias.
  • Completo: Aunque mínimo, implementa la funcionalidad central de un modelo GPT, incluyendo el entrenamiento y la generación de texto.
  • Base para Proyectos: Sirve como un excelente punto de partida para entender y construir sobre la arquitectura Transformer.

Archivos Clave del Repositorio

mingpt/model.py

El corazón del proyecto. Contiene la implementación del bloque Transformer, el mecanismo de auto-atención (self-attention) y la clase `GPT` principal.

mingpt/trainer.py

Una clase `Trainer` simple que maneja el bucle de entrenamiento, la optimización y la evaluación del modelo.

mingpt/bpe.py

Un tokenizador simple de Byte-Pair Encoding (BPE) que se utiliza para pre-procesar el texto de entrada.

demo.ipynb / play_*.py

Ejemplos y demostraciones de cómo entrenar y usar el modelo `minGPT` para diferentes tareas (generación de texto a nivel de carácter, etc.).

¿Cómo Funciona? (El Proceso)

1. Tokenización y Embeddings

El texto de entrada se divide en "tokens" (palabras o sub-palabras). Cada token se mapea a un vector (embedding). Además, se añade un "positional embedding" para que el modelo sepa el orden de las palabras. 


# En model.py:
self.tok_emb = nn.Embedding(config.vocab_size, config.embed_dim)
self.pos_emb = nn.Parameter(torch.zeros(1, config.block_size, config.embed_dim))
# ...
x = self.tok_emb(idx) + self.pos_emb[:, :t, :]

2. Bloques Transformer

Los embeddings pasan a través de una pila de Bloques Transformer. Cada bloque tiene dos sub-capas:

- Multi-Head Self-Attention: Permite que cada token "mire" y se relacione con otros tokens en la secuencia para construir una mejor representación. En GPT, es "causal" (enmascarada), lo que significa que un token solo puede ver a los tokens anteriores (para no hacer trampa al predecir el futuro).
- Feed Forward (MLP): Una red neuronal simple que procesa cada token de forma independiente.

Ambas sub-capas usan conexiones residuales ("Add") y normalización de capa ("Norm").

3. Predicción del Siguiente Token

Después de pasar por todos los bloques, la salida final se proyecta de nuevo al tamaño del vocabulario (vocab_size) usando una capa lineal. El resultado (llamado "logits") pasa por una función Softmax para obtener una distribución de probabilidad sobre cuál debería ser el siguiente token. 


# En model.py:
self.ln_f = nn.LayerNorm(config.embed_dim)
self.head = nn.Linear(config.embed_dim, config.vocab_size, bias=False)
# ...
x = self.ln_f(x)
logits = self.head(x)
