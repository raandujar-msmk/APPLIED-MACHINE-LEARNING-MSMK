# Curso de Applied Machine Learning - MSMK

Este repositorio contiene el material, código y documentos de las sesiones prácticas del curso de **Applied Machine Learning** impartido en MSMK. El contenido está organizado por sesiones temáticas que cubren desde los fundamentos hasta técnicas avanzadas de IA y despliegue.

## 🗂️ Estructura del Repositorio

A continuación encontrarás los enlaces al material de cada sesión:

    * *Conceptos básicos, configuración del entorno y primeros pasos.*
* [**Sesion 2 - Unsupervised Learning**](https://github.com/raandujar-msmk/APPLIED-MACHINE-LEARNING-MSMK/tree/main/Sesion%202%20-%20Unsupervised%20Learning)

* [**Sesion 3 - Supervised Learning**](https://github.com/raandujar-msmk/APPLIED-MACHINE-LEARNING-MSMK/tree/main/Sesion%203%20-%20Supervised%20Learning)
    * *Modelos de regresión, clasificación y evaluación de modelos.*
* [**Sesion 4 - Deep Learning**](https://github.com/raandujar-msmk/APPLIED-MACHINE-LEARNING-MSMK/tree/main/Sesion%204%20-%20Deep%20learning)
    * *Introducción a redes neuronales profundas y arquitecturas básicas.*
* [**Sesion 5 - Reinforcement Learning**](https://github.com/raandujar-msmk/APPLIED-MACHINE-LEARNING-MSMK/tree/main/Sesion%205%20-%20Reinforcement%20Learning)
    * *Agentes, entornos y algoritmos de aprendizaje por refuerzo.*
* [**Sesion 6 - Computer Vision y OpenCV**](https://github.com/raandujar-msmk/APPLIED-MACHINE-LEARNING-MSMK/tree/main/Sesion%206%20-%20Computer%20Vision%20y%20OpenCV)

## 🛠️ Requisitos Previos

Para ejecutar los notebooks y el código de este repositorio, necesitarás tener instalado **Python 3.x**. Se recomienda el uso de [Anaconda](https://www.anaconda.com/) o un entorno virtual.

Las principales librerías utilizadas a lo largo del curso incluyen:

* `numpy`
* `pandas`
* `scikit-learn`
* `matplotlib` / `seaborn`
* `tensorflow` / `keras` / `pytorch`
* `opencv-python`
* `statsmodels`

## 🚀 Instalación y Uso

1.  **Clonar el repositorio:**

    ```bash
    git clone [https://github.com/raandujar-msmk/APPLIED-MACHINE-LEARNING-MSMK.git](https://github.com/raandujar-msmk/APPLIED-MACHINE-LEARNING-MSMK.git)
    cd APPLIED-MACHINE-LEARNING-MSMK
    ```

2.  **Instalar dependencias:**
    
    Se recomienda instalar las dependencias necesarias para cada sesión según se indique en los notebooks, o instalar las librerías generales de ciencia de datos:

    ```bash
    pip install notebook numpy pandas scikit-learn matplotlib seaborn
    ```

3.  **Ejecutar los Notebooks:**

    ```bash
    jupyter notebook
    ```
    Navega a la carpeta de la sesión deseada y abre el archivo `.ipynb` correspondiente.
