Detector de Rostros Interactivo (OpenCV.js)

Esta aplicación ilustra el flujo de trabajo de detección de objetos utilizando la librería OpenCV.js, cargando un modelo de cascada Haar para identificar rostros en tiempo real desde la cámara web.

El Flujo de Detección (Paso a Paso)

  1. Carga de Librería: Se carga opencv.js y se espera el evento onload para ejecutar onOpenCvReady().
  2. Carga del Modelo: La función loadFile() descarga el archivo XML del clasificador Haar Cascade (haarcascade_frontalface_default.xml) y lo almacena en la memoria virtual de OpenCV.js.
  3. Inicio de la Cámara: startCamera() solicita acceso a getUserMedia y asocia el stream al elemento <video>. ¡Asegúrate de aceptar el permiso de la cámara!
  4. Bucle de Procesamiento: La función processVideo() se ejecuta continuamente a 30 FPS. En cada ciclo:
    • - Se captura el frame de la cámara dibujándolo en un canvas auxiliar, y luego se lee en la matriz src (cv.imread).
    • - Se convierte src a escala de grises (dst) para el clasificador.
    • - Se ejecuta classifier.detectMultiScale() en dst para encontrar rostros.
    • - Se dibujan rectángulos rojos sobre src usando las coordenadas detectadas.
    • - El resultado final (src con los recuadros) se muestra en el elemento <canvas> (canvas_output).
